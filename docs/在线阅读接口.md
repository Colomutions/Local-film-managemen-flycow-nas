# 在线阅读接口

`GET /api/v1/server-info` 在小说/漫画库可用时分别声明 `novelReading`、`comicReading`。在线接口与下载接口使用同一 Bearer token，viewer 和 admin 均可阅读；管理端删除仍需 admin。

| 接口 | 内容 |
| --- | --- |
| `GET /api/v1/comics/{id}/reading?r={revision}` | `data: {revision, pages: [{number, title, chapter, mimeType}]}` |
| `GET /api/v1/comics/{id}/pages/{number}?r={revision}` | 单页图片，页码从 0 开始 |
| `GET /api/v1/comics/{id}/cover?r={revision}` | 自定义封面，无封面时取第一页 |
| `GET /api/v1/novels/{id}/reading?r={revision}` | `data: {revision, chapters: [{number, title}]}` |
| `GET /api/v1/novels/{id}/chapters/{number}?r={revision}` | `data: {number, title, body}`，章节从 0 开始 |
| `GET /api/v1/novels/{id}/cover?r={revision}` | 保存的封面，无封面时 404 |

列表与详情增加 `canRead`；封面通过 `coverUrl` 提供相对地址。漫画通过 `hasCustomCover` 标识上传封面；下载自动封面的漫画时，客户端由已下载的第一页生成封面，避免再次传输完整图片。`r` 可选；提供后服务端要求与当前版本一致，否则返回 412。客户端应刷新列表并重新打开。未认证为 401，已删除或不可用条目不会返回正文，越界页码/章号为 400。

目录只缓存索引，不缓存整本正文。ZIP/CBZ 使用原有目录约束与自然数字排序，读取单个图片条目；PDF 通过容器已有的 `pdfinfo`/`pdftoppm` 逐页渲染，限制为 2000px、单页 50MiB 和 45 秒，渲染串行。TXT 流式扫描章节标题或按约 256KiB 分段，超长行在完整 UTF-8 字符处切割，正文只读取当前段的字节范围。图片响应带私有缓存声明，不能放入公共代理缓存。

上传 metadata 新增可选 `coverBase64`，解码上限 256KiB，只接受 JPEG/PNG/WebP，metadata 总上限 384KiB。正文摘要和去重键仍只对应原始文件；封面纳入幂等请求语义，因此重试必须复用首次请求资料。旧客户端不发送该字段时照常上传；替换时省略封面保留原封面。重复内容可补充旧条目的缺失封面，已存在的封面由管理员替换流程更新。旧小说无封面时 `coverUrl` 继续为空。

Android 管理端删除漫画使用 `DELETE /api/v1/admin/comics/{id}` 和 `If-Match: "comic:{id}:r{revision}"`，成功为 204。服务端删除共享条目及无引用的内容文件，不触及设备本地副本。删除本机上传任务记录不会调用该删除接口。

验证脚本：`dart run test/reading_api_test.dart` 覆盖鉴权、版本冲突、ZIP 页序及单页读取、PDF 渲染、TXT 章节和长行、封面往返及管理端删除。

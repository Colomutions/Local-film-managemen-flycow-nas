# 幕境内置 WhatsAV 采集进程

浏览器、影片及演员解析器、番号识别和图片下载来自本地「搜刮」项目 0.3.0。本目录随 NAS 镜像构建，不另开容器或公开端口，不运行独立片库扫描和网页。

NAS 通过标准输入输出的逐行 JSON 协议调用 `worker.mjs`。正式任务、分页游标、结果、实体映射、字段来源和审核记录保存在幕境数据库中；本目录的缓存仅负责浏览器会话、请求节奏和下载重用。每个请求最多处理一个影片或一个演员作品分页。主进程可以发送 `cancel` 中断当前请求。

厂商解析只识别页面明确字段和匹配当前来源身份的 Organization 数据，不使用站点自身的出版信息。网站没有提供的资料保持空白。网络可用性与真实网站页面变化由用户 NAS 实机验收，本地测试使用隔离数据和假浏览器。
